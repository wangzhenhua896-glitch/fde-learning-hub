# 企业知识助手（最小练习版）

完全离线、仅用 Python 标准库的中文企业知识助手练习项目。数据为**明确虚构**的「云帆科技」中文文档，与任何真实企业无关。

- 3 类角色：`intern`（实习生）/ `all_staff`（正式员工）/ `hr_admin`（HR 管理员）
- 3 级敏感级：public（5 份）/ internal（4 份）/ confidential（3 份），共 12 份文档
- **检索前先按角色做权限过滤**：无权限的文档不会进入候选集，实习生查薪酬会走拒答，而不是"查到再隐藏"

## 运行步骤

要求 Python ≥ 3.9，无任何第三方依赖，不访问网络。

```bash
cd labs/kb-assistant

# 1. 运行测试（14 个用例）
python3 -m unittest discover -s tests -v

# 2. 以不同角色提问
python3 kb_assistant.py --role all_staff --question "年假有几天"
python3 kb_assistant.py --role intern   --question "P5 的薪酬带宽是多少"   # → 拒答
python3 kb_assistant.py --role hr_admin --question "年终奖怎么算"          # → 命中 D011

# 3. 查看某角色可见的文档清单（无权限文档只显示数量，不泄露编号/标题/敏感级）
python3 kb_assistant.py --role intern --list-docs
```

## 与学习工作台阶段的对应

本项目是学习工作台「企业知识助手（虚构数据版）」的代码化练习，主要覆盖：

| 阶段 | 对应交付物 | 在本项目中的体现 |
|---|---|---|
| **s2 数据审计** | 文档清单、数据字典、权限矩阵 | `kb_docs/manifest.json`：12 条文档含编号/来源系统/维护人/敏感级/更新日期；`ROLE_VISIBILITY` 即"角色 × 敏感级"权限矩阵 |
| **s3 检索基线** | 可重建索引、检索接口、测试问题与预期来源 | `build_index()`（幂等、可重复调用）；`retrieve()` 接口契约 = 角色+问题 → 按分数排序的 `{doc_id, title, score, snippet}`；14 个测试用例即"问题 → 预期文档"清单，含 4 条越权/拒权用例 |

s4（引用与拒答）有一个最小雏形：`answer()` 返回带 `citations` 的原文摘录拼接，无命中时明确拒答。但引用只是"摘录定位"，不是模型生成内容的溯源，s4 的大部分要求尚未做。

## 检索与权限设计（简述）

- 分词：中文按二字组（bigram），拉丁字符/数字按词（`tokenize()`）。
- 打分：查询词词频求和，命中标题额外加权（×3），按分数降序、doc_id 次序作稳定 tie-break。
- 权限过滤顺序：`retrieve()` 第 1 步先算 `permitted_ids(role)` 裁剪候选集，第 2 步才在候选集内打分——不存在"先检索后隐藏"的越权窗口。
- 拒答：候选集中没有任何命中（score=0）时，`answer()` 返回固定拒答话术并给建议路径（找文档维护人）。

## 已验证（本次实测）

- 14 个 unittest 用例全部通过（`Ran 14 tests ... OK`，本机 Python 3.12.3 实测；其他版本未验证）。
- 覆盖：角色可见范围递增（5/9/12 份）、未知角色报错、实习生查不到薪酬与佣金、所有角色的结果 ⊆ 其可见集、索引覆盖全部 12 份且可重复构建、"年假"命中 D001、HR 查年终奖命中 D011、无依据问题拒答且引用为空、引用 doc_id 可回溯到 manifest、CLI 冒烟（退出码与输出）。
- 手动演示：实习生问薪酬 → 拒答；HR 问薪酬 → 命中 D010 并附引用。
- `--list-docs` 元数据不泄露：intern 的输出不含任何无权限文档的编号/标题/敏感级，只显示"另有 7 份不可见"；hr_admin 则可正常看到 D010 元数据（有权限即合法可见）。

## 未验证 / 已知边界（诚实声明）

- **没有语义检索**：bigram 词频匹配不是 BM25/向量检索，同义词、改写、错别字一律不命中；阈值只有"score>0"一档，未调优。
- **没有 LLM**：`answer()` 是原文摘录拼接，不含任何模型生成内容；"引用支持结论"只是摘录定位，未经 s4 要求的逐条人工核对。
- **权限模型极简**：manifest 是可信输入，没有防篡改/审计日志；角色与敏感级硬编码在 `ROLE_VISIBILITY`；真实系统需要组、继承、文档级 ACL 与留痕，这里均未实现。
- **只有 12 份小文档**：性能、并发、增量更新均未经测试；索引纯内存，重启即重建（本练习中这是特性不是缺陷）。
- **拒答靠"零命中"触发**：检索到不相关文档（score>0 但答非所问）时仍会返回，"检索到了但答非所问"的判定规则未实现（s4 内容）。
- **未做**：开发集/验收集分离（s5）、监控与回滚（s6）、客户验收材料（s7）。
